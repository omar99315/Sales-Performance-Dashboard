# Sales Performance Dashboard

## Project Overview
This project focuses on analyzing the Online Retail dataset to understand sales performance and discover useful business insights.

## Tools Used
- SQL
- Microsoft Excel
- Power Query
- Power BI

## Project Workflow
1. Data preparation and cleaning.
2. Data transformation using Power Query.
3. Data modeling and creating relationships.
4. Building an interactive dashboard using Power BI.
5. Analyzing sales performance and business insights.

## Dashboard Analysis
- Total Sales
- Total Quantity Sold
- Monthly Sales Trends
- Sales Performance by Product
- Sales Performance by Country
- Customer Sales Analysis

## Project Files
The ZIP file contains:
- Power BI Dashboard (.pbix)
- Original Dataset
- Project Presentation (PowerPoint)

## Project Goal
To analyze retail sales data, identify trends, and support better business decisions.ing Power BI, Excel, and SQL.
